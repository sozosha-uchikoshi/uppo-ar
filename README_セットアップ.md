『ウッポ 〜靱公園のねむり番〜』MindAR 画像認識 AR プロトタイプ。
**この3ファイルが同じフォルダにそろえば動きます。**

| ファイル | 役割 | 状態 |
|---|---|---|
| `index.html` | 本体（A-Frame 1.5.0 + MindAR image 1.2.5・CDN読込） | ✅ 用意済み |
| `targets.mind` | マーカーカードの学習ファイル（1ターゲット・アスペクト0.675） | ✅ コンパイル済み |
| `uppo.glb` | ウッポの3Dモデル | ⬜ 下記①でDLして配置 |

> `targets.mind` は確定マーカーカード（1500×2222）から作成済み。特徴点2,226 / キーフレーム11で追跡は良好。差し替え不要。

## ② GitHub Pages で公開する（HTTPS 必須）

1. 新規リポジトリ作成（名前 `uppo-ar`・**Public**）
2. **Add file → Upload files** で3ファイルをドラッグ＆ドロップ → Commit（1ファイル25MBまで）
3. **Settings → Pages → Source「Deploy from a branch」→ Branch `main`/`(root)` → Save**
4. 数分待って `https://<ユーザー名>.github.io/uppo-ar/` を開く（初回はまれに10〜20分）
5. スマホの Safari / Chrome で開く → **「はじめる」→ カメラを許可** → マーカーカードにかざす
6. 映ればOK。そのURLをQRコード化して提出。

> Netlify / Vercel でも可（HTTPSであること）。Claudeのプレビューやローカルの `file://` では動きません（カメラ・外部ライブラリ・GLBが必要）。

## ③ 実機での調整ノブ（`index.html` 冒頭 `window.UPPO_CONFIG`）

映り方がおかしいときは、ここだけ直せばOK。保存して再アップ → 再読込。

| ノブ | 既定 | 効果 |
|---|---|---|
| `UPPO_SCALE` | `0.5` | ウッポ全体の大きさ。大きすぎ/小さすぎを調整 |
| `UPPO_POS` | `'0 0 0'` | 位置 `x y z`。カードに埋まる→Yを上げる／浮く→Yを下げる |
| `ROTATE_X` | `-90` | **カードを机に平置き＝-90**／**立てて構える＝0** |
| `ROTATE_Y` | `0` | ウッポが後ろ向きなら `180` |
| `HEAD_Y` | `1.35` | 若葉が芽吹く高さ（頭の位置に合わせる） |
| `ROSE_RINGS` | 2重リング | バラの輪の半径 `r` と本数 `count`。広げる/密にするを調整 |

### 体験の流れ（`index.html` の `uppo-experience` が制御）
マーカー認識 → ねむり(呼吸) → **画面タップで覚醒**(スクワッシュ&ストレッチ) → 頭から若葉pop → 足もとにバラbloom → お別れのことば → **もう一度タップでリセット**。

若葉・バラはGLBに焼き込まず、A-Frame/Three.js側でプロシージャル生成（芽吹き・開花アニメを別実装）。GLBは形状だけを担当。

## つまずきポイント早見

- **カメラが出ない**：HTTPSでない／「はじめる」を押していない／ブラウザのカメラ許可を拒否した。Safari or Chromeで再許可。
- **ウッポが出るが向き・大きさが変**：`ROTATE_X`（平置き-90/立て0）→ `UPPO_SCALE` → `UPPO_POS` の順で調整。
- **認識しにくい**：カードを平らに・明るく・手ブレなく。印刷はA5〜ポストカード大が扱いやすい。
